DRUID（锆石 U-Pb 数据处理工具）—— 使用说明
================================================================

DRUID = Depth-Resolved U-Pb Isotope Data reduction
       （逐深度的 U-Pb 同位素数据还原）

本工具把 Qtegra/iCAP 导出的 LA-ICP-MS 锆石 U-Pb 原始数据，
还原成年龄结果表、标样质控表与深度剖面年龄域表；
其中的「剖面窗口」表可以直接交给 ADEPT 做坪年龄与 MSWD 判定。

完整说明见 README.md，本文件是给实验室日常使用的最短路径。

一、三种用法，按熟悉程度选
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【用法 1 · 网页界面】不需要碰命令行，推荐

    双击  启动数据处理工具.bat

    稍等几秒，浏览器会自动打开操作界面。
    之后全程在网页上点：选文件夹 → 看检查报告 → 点"开始处理" → 下载结果。

    要退出：直接关掉那个黑窗口。


【用法 2 · 网页界面（手动启动）】

    在本文件夹里打开命令行，执行：

        python -m druid.cli.serve_ui

    然后按提示在浏览器里打开显示的地址。
    不想自动弹浏览器时加 --no-browser。


【用法 3 · 命令行批处理】适合批量、脚本化

        python -m druid.cli.reduce_batch ^
            --dir "examples\EX2022A" ^
            --out "结果\EX2022A_U-Pb结果.xlsx" ^
            --plot

    参数说明用 -h 查看。

    examples\EX2022A 是随工具附带的示例批次（真实数据，样品名已匿名成
    S01…S48，标样保留 91500 / Ple / SRM 612）。装好环境先跑它一遍，
    跑得通就说明一切就绪。

二、数据要满足的结构
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一个批次放在一个文件夹里：

    EX2022A\
        EX2022A_LIST.csv     ← 测点序列表，第 1 列文件名、第 2 列样品名（无表头）
        EX2022A_1.csv
        EX2022A_2.csv
        ...                        ← 每个测点一个 Qtegra 导出的 CSV

要点：
  · 序列表必须叫 <目录名>_LIST.<扩展名>，与文件夹同名；
    仪器工作站导出的 .xls/.xlsx 直接用，也可以自己存成 .csv/.tsv 文本；
  · LIST 里登记的文件名不带 .csv 后缀（Qtegra 导出的默认格式）；
  · 样品名里出现 91500 会被自动识别为主标，Ple / Plešovice 识别为监控标样，
    SRM 612 识别为玻璃标样（不参与 U-Pb），其余一律当作未知样品。

网页界面会先做一次检查，缺文件、缺序列表都会当场告诉你，不必等到跑完。

· 只含标样（如 91500）而没有未知样品的「纯校准/QC 批次」也可以正常处理：
  结果只输出标样 QC 表，深度域判别与二次校正会自动跳过，网页会给出提示。

三、输出结果怎么读
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

结果 Excel 有五个工作表：

  结果        每一行一个测点：U/Th 计数率、年龄、不确定度、协和度、深度结构
  标样QC      主标与监控标样的加权平均年龄、MSWD、与推荐值的偏差
  深度剖面域  检出多个年龄域的测点，逐个域列出归一化深度 τ、年龄与 MSWD
  剖面窗口    逐窗口年龄剖面（含 1σ），给 ADEPT 做坪年龄与 MSWD 用
  运行参数    本次运行用的全部参数，便于回溯复现

判断这批数据能不能用，先看三个数字：
  1. 标样QC 里 91500 的偏差 —— 绝对值应小于 1%；
  2. 监控标样 Ple 的偏差 —— 绝对值应小于 3%；
  3. 协和度落在 90–110% 的样品占比 —— 应大于 85%。

三项都过，数据可用。

深度剖面域里的 MSWD 怎么读（与 R 端 ADEPT 同口径，两边可直接对照）：
  约 1       该域用一个年龄就能解释；
  远大于 1   可能有多个年龄混在里面，或者 σ 被低估了；
  远小于 1   σ 被高估了。
  MSWD_概率 小于约 0.05 是"不自洽"的常规警戒线。

三之二、交给 ADEPT 之前必须知道的一件事
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ADEPT 不做任何平滑、也不额外附加标定误差，这两件事必须由调用方显式声明：

    smooth                  = "none"    数据已做过 F(τ) 分馏校正，剖面本就是平的，
                                        再平滑会把真实的年龄域边界一起抹平
    calibration_uncertainty = 0         σ 里已经含了标样外部重现性，
                                        再乘 3% 就是把它算两遍

另外窗口边界也要显式给：

    lower_ablation_time = 0            DRUID 已经切好了自己的剥蚀窗口
    upper_ablation_time = 1e6          上界放到最后一个窗口之后

一个 `_1s` 列说明不了剥蚀窗口在哪里结束，所以 ADEPT 不去猜。
猜错了会静默改变参与分段的数据点数，年龄直接跑偏。

四、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q：双击 bat 没反应 / 一闪而过？
A：看窗口里的报错。最常见是 Python 环境路径变了，
   把 bat 里的第一段（找 python.exe 那段）改成本机实际路径即可。

Q：网页打不开？
A：确认黑窗口里显示了"界面地址 http://127.0.0.1:xxxx"。
   端口被占用时会自动顺延到下一个，以黑窗口里显示的为准。

Q：能不能让别人也访问这个网页？
A：不能，也不建议。服务只监听本机回环地址，
   改成对外监听会把你整个文件系统暴露到局域网。

Q：处理到一半关了网页会怎样？
A：服务端的任务会继续跑完，结果照样写盘。
   重新打开网页看不到那次任务的日志，但文件已经在了。

Q：为什么没有一个"停止"按钮？
A：Python 线程没法安全地强制杀死，做了按钮就会变成"点了没反应"，
   那是骗人。批处理通常两三分钟，等它跑完即可；
   实在要中止，关掉黑窗口。

五、代码结构（给要改的人）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    druid/
      core\        纯计算：衰变常数、年龄方程、普通铅、统计 —— 无副作用，可单独测试
      io\          读写：Qtegra 解析、序列 LIST、Excel 报表
      reduction\   单点还原：装载流程、剥蚀段识别、同位素比值
      depth\       深度剖面：滑窗、F(τ) 分馏校正、BIC 年龄域判别、出图
      webui\       网页界面：任务管理 / 业务层 / HTTP 服务 / 静态页面
      cli\         命令行入口：reduce_batch（批处理）、serve_ui（网页界面）
      workflow.py  编排层：BatchConfig 集中所有可调参数，run_batch 串起十步

想改算法就去 core 或 reduction；想改流程顺序去 workflow；
想加界面控件改 webui\static\，业务逻辑在 webui\handlers.py。

所有可调参数集中在 workflow.py 的 BatchConfig，改默认值在那里改一处。
