02名字取 Depth-Resolved，不是修辞

与只做整段积分的常规流程最大的区别：每个测点被当成一条随时间（即随坑深）变化的信号来处理——分馏按深度校正、年龄域按深度划分。

03三条不轻易改动的设计

每条都来自实测数据的教训。违背它们不会报错，只会悄悄给出错误的年龄。

原则 1

204Pb 普通铅校正必须做显著性检验

204Pb 只有几~几十 cps，204Hg 本底可达数百 cps，做差后的残余往往就是噪声。 不显著却强行扣除，等于把噪声当普通铅扣掉——对计数本来就少的 207Pb 是灾难性的。

原则 2

207Pb/206Pb 不做 F(τ) 深度校正

它是 Pb 同位素比值，几乎不随坑深分馏；而 4 s 窗口的 207Pb 仅约 130 个计数， 套 F(τ) 纯属注入噪声。它仍参与标样归一化（F76），只是不做逐深度校正。

原则 3

剥蚀区间用两级阈值，峰值比例为主

只用「本底 + kσ」会把 washout 拖尾算进来（关激光后 10 s 仍有 100~200 cps）， 把大量零信号混入积分窗口，系统性稀释比值。

05与 ADEPT 的接口契约

「剖面窗口」表的列名就是 ADEPT 的输入约定。四个参数一个都不能省——ADEPT 刻意不猜数据是否已预处理。

# 「剖面窗口」表 = ADEPT Format 4：Analysis / Time / Age68 / Age68_1s（+诊断列）
adept("EX2022A_U-Pb结果.xlsx",
      lower_ablation_time    = 0,      # DRUID 已切好自己的剥蚀窗口
      upper_ablation_time    = 1e6,    # 上界放到最后一个窗口之后
      smooth                 = "none", # 数据已做 F(τ)，再平滑会抹平真实域边界
      calibration_uncertainty = 0)     # σ 已含外部重现性，再乘 3% 是重复计入
别忘了：_1s 是 1σ，不是 2σ。拿错那列，MSWD 差 4 倍。 契约的全部细节见《两个工具的联系与数据流》。

07已知限制（我们明说）

结果是要写进文章的，边界越清楚越好用。

[!]

标样与样品计数率相差一个数量级时，二次校正是治标

主标约 1×10⁵ cps、样品约 1×10⁶ cps 时，单一线性因子消不掉高计数率下的非线性残差。 正式发表前应缩小信号强度差距（小束斑/低能量）或做死时间校正。

[!]

--deadtime-ns 默认为 0，是刻意的

死时间需由标样计数率扫描实验标定，不凭经验填；默认开启会让历史上所有未校正结果不可比。 要用请显式传参。

[!]

窗口重叠让 MSWD 系统性偏小

win=4 s / step=1 s 的滑窗引入相关性，年龄域判据因此偏宽松——方向是漏杀混合窗口， 不会错杀；下游 ADEPT 的坪判定会补上这一层。
