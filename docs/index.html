Depth-Resolved U–Pb Isotope Data reduction

DRUID

把 LA-ICP-MS 导出的原始计数率（cps）时间序列，还原成带不确定度的年龄、 标样质控表与逐深度的年龄剖面——然后交给 ADEPT 判定坪年龄与 MSWD。

从这里开始

两份文档都是单文件自包含（图表全内嵌），离线也能打开。

第一次接触请读这份

从一块岩石到一个年龄

从"放射性为什么能当时钟"一路讲到"MSWD 该怎么读"，不需要任何前置知识。 每一步都说明为什么这么做、做错了会往哪个方向偏，并给出已知的局限。

两个工具的联系与数据流

DRUID 与 ADEPT 各负责什么、数据在它们之间如何变化、边界上到底传了什么。 含一张真实测点的剖面图与实测数值对照。

8 节 · 含接口约定

快速开始

仓库里带着一个匿名示例批次（85 个测点），装好环境就能跑通。

# 跑一个批次，结果写成 Excel（五张表）
python -m druid.cli.reduce_batch --dir examples/EX2022A --out 结果.xlsx

# 秒级自检：不需要 pytest，只需要 numpy / pandas
python tests/run_all.py

# 端到端数值回归（约 1 分钟，核对标样 QC 与年龄分布）
python tests/check_example_batch.py

依赖：numpy · pandas · matplotlib · openpyxl · xlrd。刻意不依赖 scipy。
