Depth-Resolved U–Pb Isotope Data reduction

DRUID
随坑深变化的锆石年龄

把 LA-ICP-MS 的原始信号时间序列，直接转化为带不确定度的逐深度年龄剖面。

再展开一点：输入是 Qtegra / iCAP 导出的计数率（cps）时间序列， 输出是带不确定度的年龄、标样质控表以及逐深度的年龄剖面； 其中剖面表可直接交给 R 包 ADEPT 判定坪年龄与 MSWD。 DRUID 测出来，ADEPT 读出来。

02名字取 Depth-Resolved，不是修辞

与只做整段积分的常规流程最大的区别：每个测点被当成一条随时间（即随坑深）变化的信号来处理—— 分馏按深度校正、年龄域按深度划分。

03三条不轻易改动的设计

每条都来自实测数据的教训。违背它们不会报错，只会悄悄给出错误的年龄。

原则 1

204Pb 普通铅校正，必须先通过显著性检验才做

违反的代价：把噪声当普通铅扣掉，对计数本来就极少的 207Pb 是灾难性的。

204Pb 只有几~几十 cps，而 204Hg 本底可达数百 cps，两者做差后的残余往往就是噪声。 所以只在 2σ 显著时才扣，不显著就整批不扣。

原则 2

207Pb/206Pb 不做 F(τ) 深度分馏校正

违反的代价：纯属给一个本来就没有系统漂移的量注入噪声。

它是 Pb 同位素比值，几乎不随坑深分馏（随坑深漂移的是 Pb/U 这类元素对比值）； 4 s 窗口的 207Pb 仅约 130 个计数。它仍参与标样归一化（F76），只是不做逐深度校正。

原则 3

剥蚀区间用两级阈值，以峰值比例为主

违反的代价：把 washout 拖尾算进积分窗口，系统性稀释全部比值。

只用「本底 + kσ」会把 washout 拖尾算进来——关激光后 10 s 仍有 100~200 cps， 等于把大量零信号混进了积分窗口。

05先看这三个数

跑完一个批次，别急着解释年龄——先用这三个数判断这一批数据能不能用。 它们是 DRUID 质控层里三条检查项的判据原文，不是我们另拍的。

①主标 91500 偏差 本批通过
< 1%绝对值上限
本批实测 −0.25%　1059.75 Ma（n=21，MSWD 0.51）

standards.primary_bias　|criterion| = |偏差| < 1.0%（≥2.0% 判 fail）

②监控标样 Ple 偏差 本批通过
< 3%绝对值上限
本批实测 +1.81%　343.24 Ma（n=14，MSWD 1.00）

standards.secondary_bias　|criterion| = |偏差| < 3.0%（≥5.0% 判 fail）

③协和度占比 本批通过
> 85%样品占比下限
本批实测 93.75%（45 / 48 个样品测点落在 90–110%）

samples.concordance　|criterion| = ≥ 85%（< 70% 判 fail）

超过阈值不等于"不能用"，而是降级——质控层分四级， 每条检查项自己带着判据，不需要你去查文档对照：

检查passwarnfail为什么这个数
91500 偏差< 1% 1–2%≥ 2% 它是归一化锚点，偏差会整体平移全部样品年龄，不是随机误差
Ple 偏差< 3% 3–5%≥ 5% 监控标样独立于归一化，检验的是"换一个基体还准不准"
协和度占比≥ 85% 70–85%< 70% 占比掉下来通常意味着普通铅校正或剥蚀区间出了问题
三个数都过，才往下看年龄。任何一项不过，先解决仪器与标样的问题， 别急着解释地质含义——那是把分析误差读成了地质事件。 阈值集中在 qc.QCThresholds 一处，换仪器时改那里，改一处即全局生效。

06与 ADEPT 的接口契约

DRUID 输出的「剖面窗口」表， 可以直接作为 ADEPT 的输入文件。

下表列名就按 ADEPT 的 Format 4 约定取好（Analysis / Time / Age68 / Age68_1s），不用转发、不用改列名。 调用时要显式给四个参数，一个都不能省——ADEPT 刻意不猜数据是否已预处理。

# 「剖面窗口」表 = ADEPT Format 4：Analysis / Time / Age68 / Age68_1s（+诊断列）
adept("EX2022A_U-Pb结果.xlsx",
      lower_ablation_time    = 0,      # DRUID 已切好自己的剥蚀窗口
      upper_ablation_time    = 1e6,    # 上界放到最后一个窗口之后
      smooth                 = "none", # 数据已做 F(τ)，再平滑会抹平真实域边界
      calibration_uncertainty = 0)     # σ 已含外部重现性，再乘 3% 是重复计入
别忘了：_1s 是 1σ，不是 2σ。拿错那列，MSWD 差 4 倍。 契约的全部细节见《两个工具的联系与数据流》。

08已知限制（我们明说）

结果是要写进文章的，边界越清楚越好用。

[!]

标样与样品计数率相差一个数量级时，二次校正是治标

主标约 1×10⁵ cps、样品约 1×10⁶ cps 时，单一线性因子消不掉高计数率下的非线性残差。 正式发表前应缩小信号强度差距（小束斑/低能量）或做死时间校正。

[!]

--deadtime-ns 默认为 0，是刻意的

死时间需由标样计数率扫描实验标定，不凭经验填；默认开启会让历史上所有未校正结果不可比。 要用请显式传参。

[!]

窗口重叠让 MSWD 系统性偏小

win=4 s / step=1 s 的滑窗引入相关性，年龄域判据因此偏宽松——方向是漏杀混合窗口， 不会错杀；下游 ADEPT 的坪判定会补上这一层。

[!]

「不分域年龄」表里 43 / 48 个测点判「整段非常数」

不是 bug，是真实结果：整段把倾斜剖面与混合域一起算了进来。这张表按设计只用于横向对比， 能定年的只有那 5 个整段常数的点。
